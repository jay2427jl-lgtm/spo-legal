Lavnoa Box Backup: Privacy Policy

Last updated November 21, 2026.

Lavnoa Box Backup is a private tool used only by Lavnoa LLC's owner. It copies the owner's own work files to the owner's own Google Drive account using the Google Drive API. It is not offered to the public and has no other users.

The app accesses Google Drive only to upload, update and verify the owner's backup files. It does not read, collect, sell, share or transfer any Google user data to anyone else, and it does not use that data for advertising or for training AI models. Access tokens are stored only on the owner's private backup machine. The owner can revoke access at any time from their Google Account permissions page.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
